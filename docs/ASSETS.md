# Asset list

LumiTalk intentionally minimizes binary assets for fast offline startup.

The original brand system is replaced by a unified LumiTalk logo family:

- `assets/icons/icon.svg` — install icon and favicon.
- `assets/icons/lumitalk-mark.svg` — compact app-header mark.
- `assets/icons/lumitalk-wordmark.svg` — wide horizontal wordmark.
- `assets/icons/lumitalk-report-logo.svg` — print and report logo.
- `assets/icons/icon-legacy.svg` — archived former icon, not shown in the app.

- `assets/icons/icon.svg` — install icon and favicon depicting Pip.
- Sounds — generated locally with the Web Audio API; no audio files required.
- Speech — uploaded or recorded by a parent and stored privately in IndexedDB.
- Illustrations — Unicode symbols and CSS shapes with visible text alternatives.
- Backgrounds and motion — CSS gradients and non-flashing transitions.

The empty media categories contain README files so future approved assets have
clear homes. Any future image should be optimized, licensed for distribution,
stored locally, and given equivalent text.
